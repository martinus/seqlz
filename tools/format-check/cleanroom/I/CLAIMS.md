Every number and statement that follows from the rules or the tables, *Why:* sentences included. The
"Status here" column says what was checked for this list, using only `format.md` and the files in `tables/`.
Those checks were by hand, `sha256sum`, and `od | sort | uniq -c` histograms of the table files. No code was
written. "Open" means it needs a decoder, a corpus or the repository.
